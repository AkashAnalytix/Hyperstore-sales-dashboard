# Hyperstore-sales-dashboard
📊 Hyper Store Sales Dashboard | Power BI

📌 Project Overview

The Hyper Store Sales Dashboard is an interactive business intelligence project developed using Microsoft Power BI. The dashboard provides insights into sales performance, revenue trends, profitability, product performance, and category-wise sales distribution.

The main objective of this project is to analyze sales data and transform raw data into meaningful visual insights that help businesses make data-driven decisions.

🎯 Key Features

- Sales Performance Analysis: Analyze total revenue, net profit, and units sold.
- Monthly Sales Trends: Track revenue and net profit across different months.
- Top 5 Best-Selling Products: Identify the products generating the highest sales.
- Top 5 Worst-Selling Products: Identify underperforming products.
- Category-Wise Analysis: Visualize revenue distribution across Furniture, Office Supplies, and Technology.
- Sub-Category Analysis: Understand revenue contributions from different product sub-categories.
- Interactive Filters: Filter data by region, country, quarter, month, and day.

🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query (Data Cleaning & Transformation)
- DAX (Data Analysis Expressions)
- Data Visualization
- Data Analytics

📈 Key Insights

The dashboard highlights important business metrics, including:

- Total Net Profit
- Total Units Sold
- Total Unit Price
- Total Unit Cost
- Monthly Revenue and Profit Trends
- Best and Worst Performing Products
- Revenue Contribution by Category and Sub-Category

💡 Business Value

This dashboard helps businesses:

- Identify sales and profit trends.
- Understand product performance.
- Recognize high-performing and low-performing categories.
- Compare regional sales performance.
- Make informed business decisions using interactive visualizations.
